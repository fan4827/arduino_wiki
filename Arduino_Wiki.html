04 / 程式結構

setup() 與 loop() 的執行方式

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  // 讀輸入 → 判斷 → 更新輸出
}

setup() 在開機或重置後執行一次；loop() 反覆執行。

長時間等待會延遲主程式處理其他輸入。可使用 millis() 檢查時間。

05 / 讀取輸入

ADC 讀值與溫度換算

電壓 → ADC → 0–1023

UNO R3 預設為 10-bit 類比讀值。可變電阻的中間端接 A0，兩端接 5V 與 GND。

ADC 讀值 512 表示量化後的輸入電壓。換算為溫度時，需依感測器規格建立對應關係。

本教材另定教學模型：溫度 = raw × 50.0 / 1023。可變電阻用於模擬溫度變化。

W01

嵌入式系統與 Arduino

嵌入式系統把運算放進裝置，持續完成特定任務。以自動風扇為例，輸入是溫度，程式判斷門檻，輸出是風扇啟停。Arduino 是硬體與軟體生態系；UNO R3 是其中一款開發板，ATmega328P 則是板上的微控制器。

W02

UNO R3 規格

UNO R3 的 14 個數位 I/O 包含 6 個 PWM 腳，另有 6 個類比輸入。USB 可用於上傳程式；供電後由板上微控制器執行。開發板的電氣規格與腳位會隨型號改變，移植範例時需核對開發板型號與規格。

W03

setup、loop 與時間

setup() 在開機或重置後執行一次，用於設定腳位與初始化。loop() 則反覆讀取、判斷、輸出。長時間 delay() 會暫停主程式後續工作；需要兼顧輸入時，可用 millis() 的時間差決定何時更新。

概念問題：風扇為什麼要一直重新讀取溫度？

相關：W04 輸入、ADC 與量測單位W06 案例：自動風扇的控制邏輯
W04

輸入、ADC 與量測單位

數位輸入表達 HIGH／LOW；類比輸入透過 ADC 把電壓轉成數字。UNO R3 預設 analogRead() 為 0–1023。ADC 讀值沒有自動帶上 °C 單位，必須套用所用感測器的規格與校正。本教材使用可變電阻模擬輸入，並明確定義 0–1023 對應 0–50°C 的教學模型。

概念問題：analogRead(A0) 回傳 512，是否等於 512°C？

來源：S03
相關：W02 UNO R3 規格W03 setup、loop 與時間W06 案例：自動風扇的控制邏輯
W05

數位輸出、PWM 與驅動級

digitalWrite() 控制開／關；PWM 則改變高電位時間占比。UNO R3 的 PWM 常以 0–255 設定。GPIO 是控制訊號，不適合直接供應馬達電流；馬達需要合適的驅動級、電源與保護。本教材的 Arduino 程式使用板上 LED 代表風扇命令，不直接接風扇。

概念問題：為什麼 PWM 為 50% 不等於腳位一直維持 2.5V？

W06

案例：自動風扇的控制邏輯

教學設計：溫度達 30°C 開啟，降到 28°C 以下（含 28°C）關閉，28–30°C 間保留上一狀態。這種遲滯避免單一門檻附近的反覆切換；28／30 是本教材選定的示範值，並非官方規範。網頁使用滑桿模擬溫度；Arduino 範例使用可變電阻與 LED 示意，尚未接實體溫度感測器或風扇。
